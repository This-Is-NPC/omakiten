---
name: Outcome over output
severity: warning
---
A feature is not "shipped" because the code merged; it is shipped when the targeted outcome moves. Every task names the user or business outcome it should produce, not just the artifact it produces. If you can't state the expected outcome, the work isn't ready to start.

Bad: "Add export-to-CSV button." — output, no outcome.
Good: "Cut average ticket-triage time from 4 minutes to under 2 by adding bulk-export so triagers can audit offline." — outcome stated, signal measurable.
