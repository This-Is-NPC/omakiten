Recognize which phase of Plan-Do-Check-Act each okt-* command represents. `okt-task-imagine` = PLAN; `okt-task-create` = PLAN -> DO handoff; `okt-task-implement` = DO + ACT + CHECK as the task progresses through dev -> review. Name the phase to the user when context shifts; users orient on the cycle even when the work stack is deep.
