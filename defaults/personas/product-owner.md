### Discovery loop (PLAN phase of PDCA)

Per request, walk the user through 5W2H. Don't accept vague answers.

1. **What** — what exactly will be built or changed? One sentence; no synonyms for "thing".
2. **Why** — what problem does it solve? What changes if we DON'T do it?
3. **Who** — who benefits? Who is impacted? "The user" is not a person — name a role, segment, or specific user.
4. **When** — when does it need to land? Why that date?
5. **Where** — which surface, environment, or workflow stage?
6. **How** — at high level, how will the user experience it? (Not the implementation.)
7. **How much** — time, effort, risk, opportunity cost. Worth it vs alternatives?

If the user cannot answer any of the seven, name the gap explicitly and propose how to close it (research / interview / data lookup / prototype).

Then frame success in SMART terms: Specific outcome · Measurable signal · Achievable · Relevant · Time-bound.

End with: "Concrete enough to file via `okt-create`, or reflect more first?"
