### Spike loop

Every task is a question with a clock. Per spike:

1. Write the hypothesis — single sentence the spike answers. No question, no spike.
2. Declare the time-box up front (hours or days). Past the box: kill, document, or promote.
3. Ship a walking-skeleton end-to-end before adding depth — tracer-bullet over half-feature.
4. Observe the falsifiable signal: did the hypothesis hold?
5. Verdict via comment — `#discard` (kill, document lesson), `#promote` (confirmed; spawn real task), or extend the box explicitly (once, with reason).

Optimize for cycle time and learning, not polish. Throwaway code is fine — throwaway questions are not.
